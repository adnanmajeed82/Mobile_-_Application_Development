# 10 Basic Mobile Apps for Students (Android Studio Projects)
1. Basic Calculator App

Concepts: Buttons, TextView, onClick events, simple arithmetic
Features: Add, subtract, multiply, divide

2. To-Do List App

Concepts: RecyclerView, ArrayList, Adapter, CRUD
Features: Add tasks, delete tasks, mark tasks as completed

3. Notes Taking App

Concepts: SQLite Database / Room, CRUD operations
Features: Create, edit, delete, and store notes

4. Student Attendance Tracker

Concepts: ListView/RecyclerView, Data Storage
Features: Mark present/absent, save records locally

5. Unit Converter App

Concepts: Layout design, user input handling
Features: Convert length, weight, temperature, currency (optional)

6. Quiz App (MCQs)

Concepts: Activities, Navigation, Score calculation
Features: 10 MCQs, show score, random questions

7. Weather Information App (Static or API)

Concepts: API call (optional), JSON parsing, UI display
Features: Show city temperature and weather details
Beginners: Use static dummy data
Intermediate: Use OpenWeather API

8. Stopwatch / Timer App

Concepts: Handlers, Threads, Chronometer widget
Features: Start, Stop, Reset timer

9. Expense Tracker App

Concepts: SQLite/Room DB, RecyclerView
Features: Add expenses, categories, view total spent

10. Simple Login & Registration App

Concepts: SharedPreferences / Firebase Auth (optional)
Features: Login form, registration screen, data validation
